### Estilo Artístico
- **Técnica:** Ilustração 2D vetorial estilo cartoon
- **Linhas:** Contornos suaves, arredondados, sem cantos afiados
- **Sombreamento:** Flat colors com sombras suaves (cel-shading leve)
- **Proporções:** Cabeça grande, corpo pequeno (proporção infantil 2.5:1)
- **Expressões:** Exageradas e amigáveis
- **Referências:** Animal Crossing, Stardew Valley, Cozy Grove, Fall Guys

### Resoluções Padrão
```
Sprites personagens:     128x128 px (atlas 512x512)
Buildings exteriores:    256x256 px (atlas 1024x1024)
Objetos/itens:           64x64 px (atlas 512x512)
Backgrounds:             1920x1080 px (full HD)
UI elementos:            64x64 a 128x128 px
Ícones mini-games:       128x128 px
```

## 🔧 NOTAS TÉCNICAS PARA IMPLEMENTAÇÃO

### Formatos de Arquivo
- **Sprites:** PNG com transparência (alpha channel)
- **Atlases:** TexturePacker ou similar para otimização
- **Animações:** Sprite sheets ou Aseprite files
- **Backgrounds:** JPG ou PNG (sem transparência necessária)

### Estrutura de Pastas Sugerida
```
assets/
├── images/
│   ├── characters/
│   │   ├── player/
│   │   └── npcs/
│   ├── buildings/
│   ├── interiors/
│   ├── items/
│   ├── ui/
│   ├── backgrounds/
│   └── effects/
├── audio/
│   ├── sfx/
│   └── music/
└── animations/
```

### Otimização
- Usar atlases de textura para reduzir draw calls
- Comprimir PNGs com TinyPNG
- Usar resoluções múltiplas (1x, 2x, 3x) para diferentes densidades de tela
